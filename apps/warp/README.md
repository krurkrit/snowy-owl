# Warp

Warp supports custom YAML themes. Copy `snowy-owl-light.yaml` and
`snowy-owl-dark.yaml` into Warp's custom themes directory. Restart Warp or wait
for it to discover the files, then select them under
**Settings > Appearance > Current Theme**.
Warp can also sync separate light/dark themes with the OS.

For typography, go to **Settings > Appearance > Text** and choose the first
installed family in this order: **JetBrains Mono**, **Cascadia Mono**, then
**Consolas**. Warp's terminal font setting is monospace-oriented; Snowy Owl does
not force an Inter UI font where Warp does not expose that capability.

Keep **Enforce minimum contrast** enabled unless you are specifically testing
raw ANSI colors.
