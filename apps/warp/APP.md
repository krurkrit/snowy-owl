# Warp Adapter

Official custom theme YAML. Installer copies Snowy Owl theme files to the user
theme directory; font preference is documented separately.

Warp lists installed system fonts and supports font type and weight in its Text
settings. The adapter validates the ordered recommendation but does not patch
that user preference.

- Distribution: YAML
- Operating systems: Windows, macOS, Linux
- Global accessibility policy: 7.1:1 for required text pairs
- UI font preference when supported: Inter, then Noto Sans
- Monospace preference when supported: JetBrains Mono
