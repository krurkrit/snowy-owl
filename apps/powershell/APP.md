# PowerShell Adapter

PSReadLine supports token colors. Installer adds a marked Snowy Owl block to the
PowerShell profile and preserves other profile content.

PSReadLine does not control the host application's UI or monospace font.

- Distribution: PowerShell profile
- Operating systems: Windows, macOS, Linux with PowerShell 7
- Global accessibility policy: 7.1:1 for required text pairs
- UI font preference when supported: Inter, then Noto Sans
- Monospace preference when supported: JetBrains Mono
