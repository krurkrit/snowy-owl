# Slack

Slack supports Custom theme colors through Preferences → Appearance → Custom
theme. Snowy Owl intentionally does not patch Slack application files. Run
`install.ps1 -App slack`; it copies the Snowy Owl legacy color string to the
clipboard when available and prints the exact UI steps.

Light legacy palette:
`#F8F9FA,#F1F3F5,#1450A0,#FFFFFF,#18191B,#1450A0,#12633D,#A52834,#FFC107,#18191B`
