# Obsidian Adapter

CSS snippets support app personalization without packaging a community theme.
Installer copies the generated snippet into a selected vault.

CSS receives the complete compatible UI and monospace stacks, so the browser
uses each fallback in order when a font is not installed.

- Distribution: CSS snippet
- Operating systems: Windows, macOS, Linux
- Global accessibility policy: 7.1:1 for required text pairs
- UI font preference when supported: Inter, then Noto Sans
- Monospace preference when supported: JetBrains Mono
