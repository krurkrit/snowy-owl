# VS Code Adapter

Official color theme extension. Workbench, TextMate, and semantic token colors
are supported. Fonts are user settings, not color-theme properties.

The adapter validates an ordered monospace recommendation, but the user chooses
the installed family in VS Code settings.

- Distribution: VSIX
- Operating systems: Windows, macOS, Linux
- Global accessibility policy: 7.1:1 for required text pairs
- UI font preference when supported: Inter, then Noto Sans
- Monospace preference when supported: JetBrains Mono
