# Changelog

## 0.1.0

- Added a shared, 7.1:1-contrast token system with reference, hierarchy, and
  app-override validation.
- Added adapters for VS Code, Warp, Slack, Codex, Windows Terminal, PowerShell,
  and Obsidian, with idempotent installers and font fallback handling.
- Added generated themes, registry, font manifest, documentation, preview,
  dashboard, tests, CI, packaging, and maintainer workflow guidance.
- Added accessible dashboard color usage, reference, override, and tooltip
  support across canonical light and dark themes.
- Simplified operating-system metadata: unsupported platforms are omitted from
  `supportedOperatingSystems`.
